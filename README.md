# CS184/284A Fall 2026 Homework 1: Rasterizer

The write-up is in `index.html`. It uses only local assets and can be opened
without a network connection. GitHub Pages is configured by Repo184 to serve
the repository root after the changes are pushed.

- `output/pdf/hw1-writeup.pdf`: seven-page printable version of the webpage.
- `assets/`: original PNG captures from the viewer and the credited source texture.
- `my_robot.svg`: the posed robot for Task 3.
- `barycentric.svg`: the RGB triangle for Task 4.
- `mipmap.svg`: the three-size texture scene for Task 6.
- `captures.md`: exact screenshot settings and keyboard controls.

PDF page mapping: Overview and Task 1 on page 1; Tasks 2-5 on pages 2-5;
Task 6 on pages 6-7. Source attribution and the texture license are on page 7.

The implementation belongs in the separate private homework repository.
Do not add the rasterizer source code to this public write-up repository.
